# food-site  
#### A site with a variety of food stuffs, 11th April 2025  
#### By **[Shania Damar]**

## Description  
The food-site has a variety of food stuffs and can be used by anyone who has an interest in food. There is a helpline located just below the page where users can ask questions through the provided number. Social media accounts are also linked for easy contact and engagement.

## Setup/Installation Requirements  
* Clone the repository  
* Open `index.html` in a browser  
* No server setup or dependencies required  

## Known Bugs  
There are no known bugs at the moment.

## Technologies Used  
* HTML (`index.html`)  
* CSS (`index.css`)

## Support and contact details  
If you have any issues, questions, or ideas, feel free to reach out via the helpline at the bottom of the site or through the linked social media accounts.
